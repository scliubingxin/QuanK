# 半自动委托（v0.52）

QuanK 把策略信号变成**委托单**，但**不替你下单**：模拟盘按实时行情撮合；真实下单时 QuanK 在券商网页上填好委托，最后的提交按钮由你亲自点击。

## 委托单从哪里来
| 来源 | 方向 | 股数 |
|---|---|---|
| 信号变为 BUY / STRONG_BUY | 买入 | 每笔基准金额（默认 5000）× 引擎倍率 ÷ 限价，按 100 股取整（科创板最少 200 股） |
| 信号变为 SELL | 卖出 | 持仓 × 卖点卖出比例（默认 50%），剩余不足 100 股时一并卖出 |
| 信号变为 STRONG_SELL、持仓触发止损 | 卖出 | 全部持仓 |
| 手动（界面、对话、`quank order buy/sell`） | 任意 | 可指定股数和限价，否则同上 |

限价 = 现价 × (1 ± 滑点)，限制在涨跌停内，偏离现价不超过「限价偏离上限」（默认 1.5%）。委托单当天 15:00 作废。

## 风控上限（默认值）
单笔 ≤ 20000 元；每日买入 ≤ 50000 元；每天 ≤ 5 笔；限价偏离 ≤ 1.5%。买入还会按可用现金（「组合与风控」里设置的现金；模拟盘用模拟现金）和单股、行业仓位上限缩减。止损卖出不受每日金额与笔数限制。

## 模拟盘与真实下单
- **模拟盘**（默认）：买入现价 ≤ 委托价、卖出现价 ≥ 委托价时按更优价成交。初始资金默认 10 万，可在设置里修改（无成交时生效）或重置。
- **真实下单**：在「委托设置」里切换，需要确认风险提示。
  1. 「券商页面」→「打开券商页面」，在弹出的窗口里登录（登录只在内存中保存，退出 QuanK 或点「退出登录」即清除）。
  2. 打开买入页面，点「标注买入页面」，依次点击代码输入框、价格输入框、数量输入框、买入按钮；卖出页面同样标注。可选标注「当日委托」列表。
  3. 委托单上点「下单（打开券商）」：QuanK 填好三个输入框并读回核对，然后用红框标出提交按钮。**你核对后自己点击提交**，再回到 QuanK 点「我已提交」。
  4. 成交后点「回填成交」，记入持仓。

券商页面改版导致找不到输入框时，QuanK 会停止并提示重新标注，不会继续填写。

## 合规提示
量化信号不保证盈利，交易结果由你自行承担。根据程序化交易相关规定，使用程序辅助交易可能需要向券商报告，请以券商要求为准。QuanK 不保存券商密码，不会自动提交委托。
