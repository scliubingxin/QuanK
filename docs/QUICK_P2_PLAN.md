# P2 工作流：定时任务 · 智能审批 · 动态 · 简报 · 任务中心

分支 `feat/quick-p2`（自 v0.41.0 / 5f388d2）。每个模块单独提交，门槛与 P1 相同：新测试 + 累计 P1/P2 测试全过、22 个回归文件与全量单测按测试名比对无新增失败。

| 模块 | 内容 | 关键约束 |
| --- | --- | --- |
| **M1 定时任务** | 频率：仅手动 / 仅一次 / 每 N 小时 / 每天 / 工作日 / 每周指定日（本机时间）；可选智能体与工具；每次运行作为任务自己对话的一轮，过程可回看；最近 20 次运行历史；编辑、暂停、恢复 | 旧的「仅模型」任务行为不变；错过的运行恢复后只补一次；重启时中断的运行标记失败 |
| **M2 智能审批** | 「总是允许」规则：按工具 + 范围（网站域名 / 文件夹 / 命令前缀 / 文档）；规则可设有效期、仅限某任务；设置页管理与撤销；定时任务无人值守时只按规则放行，其余记为「待你确认」而不是 60 秒超时 | 删除、覆盖、发信类高风险操作永远逐次确认；规则命中写入审计记录 |
| **M3 动态** | 统一动态流：任务完成 / 失败、待确认操作、研究报告、计划完成；未读、筛选、一键处理（打开、重试、批准、忽略） | 由现有活动日志与运行记录生成，不新建云端依赖 |
| **M4 简报** | 每日简报：昨日完成、失败待处理、今日定时、待确认、新成果、记忆变更；可设生成时刻与板块，可「立即生成」 | 只用本机数据，模型可选；无模型时退化为结构化列表 |
| **M5 任务中心** | 运行中 / 排队 / 今日计划 / 历史一页看全，支持停止、重试、跳过下一次 | 与现有运行队列共用状态 |
