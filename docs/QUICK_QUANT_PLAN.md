# QuanK 量化（本机私有引擎）

## 定位
QuanK 只提供一个**通用的本机量化引擎外壳**：导入、同步、启停、日志、设置、股票池与个股详情界面、图表、对话工具和提醒。
策略本身（代码、模型、参数、数据）始终留在用户自己的私有项目里，不进入本仓库、不进入安装包。

## 接入约定：wb-engine.json
私有项目根目录放一个 `wb-engine.json`，描述：
- `engine`：入口脚本（项目根目录下的 .py）、健康检查路径、需要的 Python 包、可选的 Python 路径；
- `auth`：本机登录接口与字段名；
- `endpoints`：股票池、信号、行情、AI 研判、股票池增删等接口路径（`{code}` `{uid}` `{name}` 占位）；
- `fields`：把引擎返回映射到 QuanK 的通用字段（档位、综合分、调整前分数、倍率、理由、约束与风控、评分构成、指标、模型概率、仓位建议、回测摘要、价格 / 评分序列、回测曲线与操作）；
- `config`：引擎配置文件名、QuanK 写入的键（本机地址与端口、随机本机登录、AI 网关）、只导入一次的段落、需要丢弃的凭据类键；
- `sync.exclude`：同步时不复制的文件（正则）。

QuanK 固定不复制：版本库与缓存目录、日志、数据库文件、名字里带 secret 的文件、引擎配置文件本身。

## 安全
- 引擎只监听 127.0.0.1，使用随机生成的本机登录，口令存系统安全存储；会话只保存在主进程。
- 推送类功能由 QuanK 负责，引擎自身的推送关闭。
- 对话工具把信号摘要交给已配置的模型，用于回答问题；仅供研究，不构成投资建议。

## 模块
| # | 内容 |
|---|---|
| Q1 | 引擎外壳与「量化」页：引擎卡、股票池卡片、个股详情（含价格 / 评分与回测曲线）、AI 研判；对话工具 app_quant_status / signal / scan / insight / pool_add / pool_remove / open |
| Q2 | 个股详情增强：分钟级行情、信号点标注 |
| Q3 | 提醒与简报：交易时段轮询股票池，档位变化进入「动态」并发系统通知；盘前简报；每日简报增加量化板块 |
| Q4 | 持仓与定投：查看持仓与建议仓位，记录买卖（逐次确认，无人值守转「待你确认」） |
| Q5 | 日报与复盘：引擎日报、AI 纠正率、信号结果评估 |

## 进度
- Q1（已完成）：本机私有引擎外壳，适配文件驱动；侧栏「量化」页；对话工具；引擎已配置时股票类问题无需打开工具开关。
- Q3（已完成）：盯盘与提醒——交易时段（工作日 09:30–11:30、13:00–15:00）按 5 / 10 / 15 / 30 / 60 分钟逐只重新计算股票池，档位变化记入「动态」（新增「量化」筛选）并发系统通知，点开直达个股详情；工作日开盘前（默认 09:15）生成一份盘前量化简报；每日简报新增「量化信号」板块（有股票池时出现）；「量化」页显示盯盘状态与最近信号变化；对话工具 app_quant_watch（修改需确认），app_quant_status 返回盯盘设置与最近变化。不识别法定节假日（休市日行情不变，不会产生变化提醒）。
- Q4（已完成）：持仓与定投——wb-engine.json 新增 position / positionRecord / plan / planSet 接口和 holdings / planFields / planOptions 映射；「量化」页新增持仓表（持仓、成本、现价、市值、浮动盈亏、合计）、卡片持仓行、个股详情「我的持仓」（指标与最近成交）、「记录买卖」与「定投计划」表单；记录成交前校验方向、价格、股数（整手）、卖出不超过持仓、日期不晚于今天，记录后清除该股信号缓存；修改定投计划后清除全部信号缓存；对话工具 app_quant_holdings（只读）、app_quant_trade_record、app_quant_plan_set（逐次确认，无人值守转「待你确认」）。QuanK 不会下单。
- Q5（已完成）：日报与复盘——wb-engine.json 新增 reports 列表（脚本、参数、结果 JSON / Markdown 路径、每日或手动、字段映射：摘要、指标、告警、建议）；QuanK 只在引擎目录内运行列出的 .py 脚本（不经 shell，10 分钟超时，路径限定在引擎目录），「量化」页新增「日报与复盘」卡片（指标、摘要、告警、生成 / 查看）、报告查看窗（指标、告警、建议、Markdown 正文）、「自动生成」设置（工作日收盘后指定时间，每天一次，只跑每日报告）；结果进入「动态」、每日简报「量化信号」与系统通知；对话工具 app_quant_report（读取或本机重新运行）、app_quant_report_auto（确认）。
