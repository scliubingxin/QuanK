# P4 创作：可视化 · 信息图 · 小应用 · 写作风格 · 图片生成 · 结构化对比（任务说明，可中断续做）

仓库 `wb-par/quick`，分支 `feat/quick-p4`（自 feat/quick-p3 / c31c048 = v0.43.0）。

## 用户选择（2026-11-19）
- 六个模块全做：可视化报告与仪表盘、信息图与海报、小应用搭建、写作风格档案、图片生成、结构化对比。
- 图片生成：国内图片模型，OpenAI 兼容接口（如硅基流动、智谱 CogView；通义万相按其接口适配），用户自填 API Key。
- 顺序：先做完全本机的 M1 可视化、M2 结构化对比、M3 信息图；再做 M4 小应用；最后 M5 写作风格、M6 图片生成。

## 统一原则
- **数字来自真实数据，不来自模型。** 可视化与对比里，模型只决定「怎么看」（选哪列、怎么分组聚合、画什么图），聚合与数值由本机代码对原始数据计算。
- **成品都是可保存、可再打开、可导出的成果**：存入成果中心（artifacts），可导出 PNG / PDF / HTML（对比另可导出 XLSX / DOCX）。
- **运行在现有双层隔离沙盒里**（`willbuddy-preview://local/html/`）：不联网、不能访问本机文件和应用接口。ECharts（Apache-2.0，6.1.0）作为固定、校验哈希的本地资源随包分发，不从网络加载。
- **模型生成的是结构化规格（JSON），不是任意代码**；只有 M4 小应用允许模型写 HTML/JS，且仍在沙盒内、数据只存在该应用自己的本机存储里。
- **发给模型的内容**：M5 写作风格学习、M6 图片描述会发给用户配置的模型 / 图片接口，界面上明确提示；其余模块只发列名、样例行和统计摘要（可选不发样例）。

## 规则（与 P3 相同）
- 代码由主助手编写（仓库外暂存 + 精确替换补丁），编码代理只负责测试、提交、推送、打包。
- 每个模块一个提交 `[p4-mN]`；门槛：新测试单跑 10 次、相关批次 3 次、全量与 `_baselines/p2-ux2.fails.txt` 按名比对无新增；复查新增失败时**只单跑那一条**（`--test-name-pattern`），不整文件跑。
- 测试命令以 liubingxin 身份运行，PATH 去掉 `/var/root/*`，python3 用带 python-docx / openpyxl 的版本。
- 用户已授权模块通过门槛后推送 GitHub main；**发布 Release 先问**。

## 模块
| # | 模块 | 要点 |
|---|---|---|
| M1 | 可视化报告与仪表盘 | 数据源：成果中心的 XLSX / CSV、对话附件、已同步的连接数据；本机解析为表（类型推断：数字 / 日期 / 文本）；模型产出 dashboard 规格（KPI 卡、折线、柱状、堆叠、饼 / 环、散点、表格、筛选器），本机按规格聚合（sum / avg / count / min / max、按月 / 周 / 日）；ECharts 渲染；交互筛选；导出 PNG / PDF / HTML；对话中 ```dashboard 代码块与工具 `dashboard_create` |
| M2 | 结构化对比 | 「A、B、C 对比」输出统一维度表：每格「值 + 单位 + 来源」，找不到写「未找到」，定性判断单列；可联网检索（复用浏览器工具）或只用资料；导出 XLSX / DOCX；对话中 ```comparison 块渲染为表 |
| M3 | 信息图与海报 | 版式模板：数据摘要卡、流程、时间线、对比、海报、清单；品牌套件（主色、辅色、logo、字体）在设置里保存；模型产出版式规格，本机模板排版（文字为真实文本，可在编辑面板改字）；导出 PNG / PDF |
| M4 | 小应用搭建 | 一句话生成单文件 HTML 小工具；在隔离沙盒运行；每个应用独立本机存储（经宿主中转、有配额）；版本历史、改名、复制、删除；「修改这个应用」继续对话迭代；定时任务可调用应用的声明式动作（只读） |
| M5 | 写作风格档案 | 从用户选定的文档、已发邮件（连接）学习：句长、用词、结构、称呼、结尾、禁用表达，生成可读的风格档案；「用我的口吻写」/ 智能体开关自动带入；档案可查看、编辑、删除；学习前明确提示会发给模型 |
| M6 | 图片生成 | 设置里配置图片接口（预设：硅基流动、智谱 CogView、通义万相；自定义 OpenAI 兼容 `/images/generations`）；生成插图、封面、配图；本机去背景（简单阈值 / 纯色背景）；插入 Word / PPT / 信息图；遵守内容限制（不生成真实人物、写实人像等） |
