# QuanK PPT 编辑器功能规划

## 实际文件诊断

用户提供的 14 页 PPTX 中，第 1 页是标题与一组项目符号，共两个形状，未包含图片；它本身的设计信息密度和视觉元素有限。现有 LibreOfficeKit 900×700、scale=15 画布在该文件上可见宽度 13500 文档单位，而页面宽 19201，因此右侧被裁切。适应窗口 scale=22 后可见宽度 19800、可见高度 15400，覆盖 19201×10801 页面。修复只针对视口显示，不改变 PPTX 内容。真实文件仅用于私有验证，不进入源码包。

## 用户工作流与页面结构

窗口顶部提供文件名、保存状态、保存和 AI 对话。操作区按“开始 / 插入 / 设计 / 切换 / 动画 / 放映 / 视图”组织；只呈现已经连接实际操作的功能，未实现的项目不以可点击按钮冒充。左侧为可重排的真实幻灯片缩略图和添加页面，中间为完整画布，底部为演讲备注与缩放，右侧为可收起的 AI 与属性面板。当前仅支持左侧文字页面列表、缩放、页面适配、基础选区和编辑，并非完整参考界面。

## 开发与验收顺序

1. 画布与导航：针对真实 PPTX 实现等比适应、放大缩小、滚动、清晰的真实缩略图、当前页高亮、键盘导航；检验缩放前后选区和点击坐标、切页时草稿、10–100 页性能和关闭取消。不同操作系统的字体发现与替换要显式提示，不修改原件。
2. 文本与对象：提供字体、字号、颜色、段落对齐、项目符号，文字框、形状、图片的插入/选中/拖拽/大小及层级；操作进入现有文档版本、撤销、审计和失败恢复。保持原格式和其他页面内容，复杂对象未经验证时保守拒绝。
3. 页面与母版：安全插入、复制、删除、重排、版式选择，备注读取编辑与保留；对母版、主题、背景进行带版本守卫的修改。含动画/图表/媒体的原稿必须往返对比，防止操作时丢失对象。
4. 设计与 AI：将用户资料、来源和品牌规范分离为大纲、版式方案、页面对象、渲染验收四步；支持标题与内容分层、可编辑图表和图片、溢出/遮挡检查、幻灯片级修改与撤销。不得以项目符号模板或固定演示回复声称已达到专业设计水平。未确认的事实标注来源或待核验。
5. 切换、动画和放映：从无切换与有限淡入开始，逐步支持可验证的对象动画、时长、次序以及全屏演示；兼容性通过 PowerPoint/WPS 与 Mac 实机验证。未知动画优先保留原 XML，无法保留时禁止破坏性保存。
6. 性能与交付：真实文档分别测试首屏、切页、双文档隔离、崩溃恢复和高分辨率缩放；Apple 芯片原生严格签名、安装、系统字体、IME 和 Gatekeeper 独立验收，不能用 Linux 结果代替。

## 当前限制

当前 0.37.127 只修复用户真实文件的初始裁切和页面外黑边，保留原有选区与编辑能力。页面缩略图、完整工具栏、直接对象编辑、备注、母版、放映与高质量自动排版仍待实现；没有承诺与参考产品功能或渲染完全一致。
