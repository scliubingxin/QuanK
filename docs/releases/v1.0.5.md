# QuankSight 量见 v1.0.5

## 修复

- **Office 编辑**：修改字体会导致编辑器退出，现已修复；字体列表改为读取本机实际可用的字体，异常参数只提示、不再中断编辑。
- **半自动委托**：在「自动化 › 半自动委托」点击「下单 / 撤销」后按钮无反应，现在确认卡片直接显示在对应委托单下方。
- **动态计数**：点击「全部标为已读」后，首页、侧栏角标和「需要处理」的数字立即刷新；今日简报的「需要你处理」改为实时计算，并包含待确认的委托单。
- **工作台**：首页不再堆叠已处理的授权记录和授权卡片，待处理事项统一显示在输入框上方的「N 项待授权」提示条中。
- **前往授权**：点击后跳转到事项所在位置——委托单跳到「半自动委托」并高亮该行，对话中的授权打开对应对话，Coding 任务打开任务详情，其余授权可在「动态」中直接处理；多项待授权时提供「查看全部」。

## 界面

- 侧栏收起时 logo 调整为 28px 并与导航图标居中对齐。
- 侧栏展开时在 QuankSight 旁显示版本号标签。

## 已知问题

- 内置字体暂不含中文衬线字体，字体列表中暂不提供「宋体」。

## 升级

直接下载新版 DMG，将 QuankSight 拖入「应用程序」并替换旧版本即可，数据与设置保留。首次启动如出现钥匙串提示，请点「始终允许」。
