# QuankSight 量见 v1.0.8

## 改进

- **Coding 任务详情页改版**：与对话、其他右侧页面使用同一套卡片、圆角、字号与配色。顶部显示任务标题、智能体、分支与状态；新增「读取上下文 → 修改代码 → 运行测试 → 回测对比 → 待合并」进度条；智能体输出按对话格式排版；工具调用与终端输出改为可折叠的等宽代码块，带复制按钮并限制高度；文件改动按 +/− 分色显示；回测对比改为指标表，变化列改善为绿色、变差为红色；「合并」「放弃」固定在页面底部。窄面板（360–480 px）与深色模式均已适配。
- **授权确认更醒目**：对话里的授权卡、输入框上方的「前往授权」条、Office AI 修改确认和 Coding 任务的授权提示统一为琥珀色左边框与浅色底，按命令 / 文件 / 联网显示图标；「允许一次」为主按钮，「本任务内允许」次要，「拒绝」为描边红色按钮，均有键盘焦点框；新请求出现时轻微闪烁一次（系统开启「减少动态效果」时不闪）。
- **回测操作记录**：操作列显示「买入」「回补买入」等中文名称，不再显示引擎代码；量化页引擎卡片只保留一个主按钮。

## 修复

- **Coding 任务页跳动**：Coding 智能体运行时，右侧任务页每次有新输出都会跳回顶部附近，正在看的内容被推出画面。现在刷新时保持当前阅读位置；停在页面最底部时会继续跟随最新输出。
- **授权请求不再推开内容**：Coding 任务的授权请求改为任务页顶部一条固定的单行提示（如「需要你的授权 · 运行测试」），按钮直接在提示条上；点开后在浮层里查看详情和已处理记录；输入框上方的「前往授权」会自动展开这条提示。
- **投研 PPT 无法生成**：安装版里「做一份投研 PPT」和每日迭代后的汇报 PPT 会生成失败（提示无法打开 build_deck.py）。原因是 PPT 引擎文件被打包进应用归档，内置 Python 读不到。现已改为随应用解包存放，安装版可以正常生成。

## 升级

直接下载新版 DMG，将 QuankSight 拖入「应用程序」并替换旧版本即可，数据与设置保留。首次启动如出现钥匙串提示，请点「始终允许」。
