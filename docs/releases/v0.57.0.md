# QuanK v0.57.0 发布记录

## Coding 智能体

- 在「智能体 → Coding 智能体」检测和配置本机 ACP 代理，支持 WorkBuddy、codebuddy-acp、Codex、Kiro 和 DeepSeek。助手将「编写代码」「迭代代码」等请求自动路由到 Coding 智能体。
- 任务按[《量化代码迭代规范》](../../desktop/services/QUANT_CODING_SPEC.md)运行，读取任务启动时生成的只读上下文快照，在独立的 `quank/iter-*` 分支修改代码。
- 在任务详情查看测试结果、同口径回测的前后对比及代码差异。用户确认后由 QuanK 合并改动并重启策略引擎。
- Git 操作限于任务迭代分支，禁止代理自行合并、推送或修改远端配置。
- 运行模式可选「自动」「仅外部」「仅内置」。自动模式可回退到内置编码，内置沙箱默认禁网。

- **对话内授权**：确认类弹窗改为对话或任务页签内的授权卡片，提供「拒绝」「允许一次」「本任务内允许」，高风险操作仅提供「拒绝」「确认」。输入框上方的待授权提示条支持跨会话计数与跳转。窗口在前台时通过卡片提示，窗口在后台时每项只发一次系统通知。联网授权仅限本次命令。钥匙串、锁定和文件选择器仍使用系统弹窗。

## 量化设置

- 新增「启动时自动启动本地引擎」开关，默认关闭。
- 运行策略时优先使用 PATH 中的 Python。

## 已知限制

- WorkBuddy CLI 需要先登录或配置 `CODEBUDDY_API_KEY`。
- 暂不支持在任务页签内嵌入代码编辑。
