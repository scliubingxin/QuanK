# QuankSight 量见 v1.0.6

## 修复

- **授权卡片位置**：对话中「需要你的授权」卡片改为显示在执行步骤下方、紧挨当前进行中的操作；输入框上方的「前往授权」提示条不再重复列出当前对话里已显示的授权。
- **文档空间**：文档空间上限由 100 个 / 16 MiB 放宽到 200 个 / 64 MiB。空间不足时先自动清理较早的历史版本（不影响任何文档的当前版本）；仍然不够时，提示当前用量和清理位置（「资料库 › 成果中心 › 文档」中的「删除文档」）。

## 界面

- 资料库文档列表的标题处显示文档空间用量（已用 X / 64 MiB）。

## 升级

直接下载新版 DMG，将 QuankSight 拖入「应用程序」并替换旧版本即可，数据与设置保留。首次启动如出现钥匙串提示，请点「始终允许」。
