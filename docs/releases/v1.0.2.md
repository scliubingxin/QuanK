# QuankSight 量见 v1.0.2 发布记录

日期：2026-11-26。版本号 v1.0.2（v1.0.1 的 tag 已推送，按规则不重打 tag、不强推，改发新版本）。

安装包：`QuankSight-v1.0.2-mac-arm64.dmg` / `QuankSight-v1.0.2-mac-arm64.zip`（下载名 `QuankSight-mac-arm64.dmg`）。

## 升级提示

**第一次打开 v1.0.2 时，macOS 会弹出「QuankSight 想要使用储存在钥匙串中「QuanK Safe Storage」中的机密信息」，请点「始终允许」。** 点「允许」只对本次有效，下次开机会再问；点「拒绝」则旧密钥读不出来，量化引擎、远程引擎令牌和 Coding 代理密钥需要重新填写。

## 变更

### 1. 钥匙串迁移修复（v1.0.1 改名遗留）

- 现象：v1.0.1 把进程名改成 QuankSight 后，钥匙串条目变为「QuankSight Safe Storage」，而 v1.0.0 及更早保存在「QuanK Safe Storage」里的密文读不出来，量化引擎、远程引擎令牌、Coding 代理密钥全部失效，界面报 `Error while decrypting the ciphertext provided to safeStorage.decryptString`。
- 现在依次尝试用 `QuanK`、`Actwill AI` 两个旧钥匙串身份解密，解开后立即用 `QuankSight` 身份重新加密并写回；未能在第一次尝试中解开的密文会继续交给下一个旧身份。
- 之前漏掉的字段补齐：所有以 `Sealed` 结尾的键（如 `tokenSealed`、`passSealed` 以及 `envSealed` 之类的映射）与 `sealed` 映射一起纳入迁移，`v1:` 前缀（`adminSealed`）保持原样。
- 本机引擎管理员密码读不出来时自动重建，不再要求用户手动清空设置。
- 实在解不开的项不再静默失败，界面提示「请在量化设置里重新填写」。
- 迁移计数按目标身份单独统计，改名到新身份后重新获得 3 次尝试机会；已能从当前身份打开的密文不会被重复迁移。

### 2. Office 编辑窗口

- 画布撑满整个窗口，不再留大片空白。
- 打开时的默认缩放按格式决定：PPT 适合页面（上限 90%）、Word 适合宽度（上限 100%）、Excel 100%；页面居中显示。
- 缩放范围 25%–200%，每次从当前值 ±10%，两次「−」再两次「+」按原路回到原值（87% → 77% → 67% → 77% → 87%）；支持 ⌘+ / ⌘− / ⌘0 快捷键和触控板捏合缩放。
- 工具栏固定在窗口顶部，不再随内容滚动。
- 底部新增状态栏：PPT「第 X 张 / 共 N 张」、Word「第 X 页 / 共 N 页」、Excel「工作表 X / N」，同一行附缩放控件。
- 窗口标题显示真实文件名。
- 修复 AI 写入确认卡在编辑窗口里渲染成「[object HTMLDivElement]」竖条、点不到「确认」的问题。

### 3. 投研 PPT

- 信号页绑定当前这只股票，不再串成别的标的。
- 最大回撤显示为负值。
- 交易次数改为「完成交易（卖出）」，口径写清楚。
- 只有「待披露」的表格改成一句说明，不再输出空表。
- 没有可比公司时改为估值卡片加「估值说明」。
- 要点标记与文字对齐，不再错位。
- 行情 KPI 只显示现价。
- 时间线排版优化。
- 成交额按亿元 / 万元显示。
- 数据时间改为北京时间。

### 4. 界面

- 工作台不再堆叠已经处理过的授权结果。
- 行情每秒刷新时页面不再跳回顶部。
- 「全部标为已读」后会提示仍待处理的项，并切换到「待处理」。
- 半自动委托点「下单 / 撤销」后自动滚动到确认卡。
- 成果中心对空文档做了保护，不再报 `slice` 错误。
- 同一页面不再左右重复打开，已在别处显示时直接切过去。
- 信号标签统一显示中文（`buy` → 买入等）。

## 校验

- `node --check`：仓库内 772 个 .js / .mjs / .cjs 逐文件检查，除 `vendor/genoffice-html2docx/src/browser/core/paragraphs-document.js` 的既有 `Illegal return statement`（v0.45.0 引入的第三方代码，与基线一致）外全部通过。
- 单元测试：逐文件运行，失败文件数与基线一致（39 个已知失败），无新增。
- 冒烟：`desktop/scripts/smoke-ipc.mjs` 在隔离数据目录下通过（107 个 IPC 通道、15 个只读调用、3 个页面）。
- 编辑窗口实测（隔离数据）：PPT 默认 87%、页面偏移 0/0、状态栏「第 1 张 / 共 10 张」；Word 100%、「第 1 页 / 共 1 页」；Excel 100%、「工作表 1 / 2」；两次 −、两次 + 依次为 87% → 77% → 67% → 77% → 87%；量化页滚动后 3 秒内 `scrollTop` 不变。
- 打包产物字节数与 sha256 见 GitHub Release 与下载页校验表。

## 已知限制

- 既有的环境类失败（本机 Python 包、LibreOfficeKit 运行时、并发端口占用）与基线一致。
- 应用未签名 / 未公证，首次打开若被 Gatekeeper 拦住，右键「打开」或在「系统设置 → 隐私与安全性」里点「仍要打开」。
