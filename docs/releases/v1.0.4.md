# QuankSight 量见 v1.0.4 发布记录

日期：2026-11-27。版本号 v1.0.4。

安装包：`QuankSight-v1.0.4-mac-arm64.dmg` / `QuankSight-v1.0.4-mac-arm64.zip`（下载名 `QuanK-latest.dmg` / `QuanK-mac-arm64.dmg`）。

## 升级提示

1. **先退出旧版本**：在 QuankSight 窗口里按 **⌘Q** 退出（只关窗口不算退出），再把新的 `QuankSight.app` 拖进「应用程序」覆盖旧版本。
2. 首次打开若 macOS 询问钥匙串「QuanK Safe Storage」，点「**始终允许**」（从 v1.0.1 及更早升上来的用户才会遇到；v1.0.2 之后已迁移过的不再询问）。
3. 应用未签名 / 未公证。若被 Gatekeeper 拦住，到「系统设置 → 隐私与安全性」点「仍要打开」。

## 变更

### 侧栏收起后 logo 不再溢出

- 现象：手动收起侧栏（顶栏左上角的方格按钮）后，logo 仍是展开态的 54px，而收起后的图标栏只有 66px 宽，logo 被顶出右边缘并裁掉右下角，也不与下方的「+ 新建任务」按钮、导航图标对齐。
- 原因：v1.0.3 给展开态加的 `.sidebar .brand-mark{width:54px!important}` 同样命中了收起态，且优先级高于原有的收起态规则；`.brand` 的内边距也被后写的展开态规则盖掉。
- 现在收起态：logo **36px**，与「+」按钮、导航图标共用同一条中轴（中心偏差 0），右边缘留出余量不再裁切；文字隐藏且不占位；logo 与「+」按钮、以及「+」按钮与第一个导航图标之间的纵向间距一致。
- 展开态完全不变：侧栏 248px、logo 54px、两行品牌（`QuankSight` / 量见 · 量化工作，见机即获）。
- 窄窗口（≤980px）自动收起的路径 v1.0.3 已有 44px 兜底，本版未改动。

## 校验

- `node --check`：对所有 .js / .mjs / .cjs 逐文件检查。
- 单元测试：逐文件运行，失败文件数与 v1.0.3 基线一致（39 个已知失败），无新增。
- 冒烟：`desktop/scripts/smoke-ipc.mjs` 在隔离数据目录下通过。
- 收起态实测（打包后的 app，隔离数据）：侧栏 66px、logo 36×36、右边缘 50.5（< 62）、与「+」按钮和导航图标中心偏差 0px、logo→「+」与「+」→导航间距均为 17px。
- 打包产物字节数与 sha256 见 GitHub Release 与下载页校验表。
