# QuanK v0.58.0

## 页签内 Office 编辑与 AI Office

- Word、PowerPoint 和 Excel 在右侧页签打开即可编辑，也可使用独立窗口。打开自己的文档编辑无需授权。
- 选中文字即可使用浮动工具条设置样式，按 ⌘J 唤起 AI。支持润色、改写、扩写、缩写、翻译、换语气、续写、转表格、转图表和问 AI。
- AI 结果以中文按词显示差异，可接受、拒绝或重试。Writer 以修订形式保留接受的修改。
- 助手可读取大纲和正文、查找内容、修改文档或刷新量化数据。修改先预览再授权，7 天内可撤回。
- 支持自动保存、版本历史、外部修改冲突处理、崩溃后恢复及退出保护。

## 性能

72 页 PPTX 首屏 P90 为 1.48 秒。按键回显 P95 为 Writer 47.9 毫秒、Impress 35.7 毫秒。暖机后的 DOCX 首屏约 0.2 秒。

## 已知限制

- 带版式的新幻灯片及图表原生数据绑定入口暂时隐藏。
- 大型 PPTX 的单文档内存增量约 280 MB。
- 系统拼音候选窗的截图证据待补。
- 全量测试基线有 143 项既有失败，环境缺少 `pdftotext` 和 LibreOffice 动态库。与 main 对比，新增失败为 0。

## 安装与升级

适用于 Apple 芯片 Mac，最低支持 macOS 12。打开 DMG，将 QuanK 拖入「应用程序」。升级前按 ⌘Q 退出旧版 QuanK，再替换应用并重新启动。ZIP 可解压后将 QuanK 移入「应用程序」。若 macOS 阻止首次打开，可使用 DMG 内的「首次打开」脚本。
