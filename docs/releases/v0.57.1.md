# QuanK v0.57.1

1. 编辑弹窗使用固定头部与按钮栏，正文独立滚动，覆盖 720px 暗色窗口。
2. 环境变量改为紧凑表格，敏感输入默认隐藏，可按需显示。
3. 连接测试可取消，最多 30 秒，回收进程组并显示中文结果。
4. Coding 智能体纳入智能体分类，统一卡片与连接状态操作。
5. 本机检测列表显示路径悬停、npx 缓存提示和已添加状态。
6. 智能体支持绑定对话和 Coding 子智能体，迁移原默认绑定与回退值，支持只读委托。
7. Coding 任务移入自动化，详情仍在右侧页签打开。
8. 预览 PDF 导出按钮使用同套线性图标。
9. 预览菜单保留下载、版本历史和成果中心定位。
10. Office 先显示窗口再载入，按文件体积计算期限，窗口内重试，提示随页面作用域变化。

本轮视觉修正包括 Coding 设置卡片与描边按钮、环境变量行分隔线、无引号参数与原参数边界保留、分类分段控件和专属统计、自动化任务状态徽标。

## 安装与升级

仅支持 Apple 芯片 Mac。退出已运行的 QuanK 后，将 DMG 中的 QuanK 拖到「应用程序」；升级选择替换。如首次打开被系统拦截，可使用安装盘内「首次打开」命令。安装包采用 ad-hoc 签名。ZIP 可解压安装，完整校验值见 GitHub Release。
