# QuanK v1.0.0 发布记录

日期：2026-11-25。这是 v0.58.0 之后的正式版本，重点修复启动白屏，并把 Office 编辑与投研 PPT 生成拆成独立路径。

## 变更

### 1. 白屏修复（V100-1）
- **展开状态不跨重启**：`qk.pageTabs` 不再持久化 `wide:true`；启动时一律以 `pageWide=false` 还原，旧版本写入的 `true` 被忽略；`savePanel()` 始终写 `wide:false`。
- **渲染失败兜底**：`renderPanel()` 把原主体拆到 `renderPanelTab()` 并用 try/catch 包住；没有页签或页签渲染抛错时清掉 `pp-wide`、恢复主区域，并在页签内显示可关闭的错误提示。CSS 增加 `:has(#pagePanel)` 守卫。
- **Office 画布缩放回环**：ResizeObserver 回调合并到单个 rAF，按 `contentRect` 取整尺寸去重，缩放用 1% 相对误差判断，识别 A→B→A 滚动条振荡后保持当前缩放，并设 `scrollbar-gutter: stable`。瓦片缓存不再每帧被清空。
- 现场验证：同一份 `qk.pageTabs`（`wide:true` + pptx 页签）分别启动 v0.58.0 与 v1.0.0：前者 `.main display:none`、0×0、可见元素 0；后者 `display:flex`、535×792、可见元素 388～446，展开/还原 5 轮均正常。

### 2. Office 页签只读预览、编辑在独立窗口
- 右侧页签只挂只读预览，不再挂画布和编辑工具栏；编辑按钮打开专属原生窗口，同一文档只保留一个窗口，保存后回流新版本。
- 窗口 IPC 只绑定确切的 owned main frame，忽略渲染进程伪造的 session/document id；所有 BrowserWindow / webContents 的可选调用都走 `safe()` 防护，窗口销毁过程中不再抛错。

### 3. 投研 PPT 引擎
- 新增 `research` 主题，按真实行情、财务与量化数据生成演示文稿（产品、研报、投研三类），页面含数据出处与免责声明。
- 堆积柱「亏损」系列的数据标签改为白字，保留 `invert_if_negative = False`，避免深色文字压在红柱上。

### 4. 运行时与内置 Python
- 运行时根目录与可执行文件两侧都做 `realpath` 规范化，修复 `/tmp` → `/private/tmp` 符号链接导致的路径校验失败。
- 主进程启动的所有内置 Python 子进程（Office worker、预览池、kit、本地 ONNX、CLI runner、量化引擎）env 统一带 `PYTHONDONTWRITEBYTECODE=1`；准备脚本使用 `python3 -B` 与 `--no-compile`；LibreOffice 转换使用独立的 `-env:UserInstallation` 临时 profile。应用包内不再新增 `.pyc`。

## 已知限制
- PE / PB 历史分位暂缺。
- 大 PPTX 单文档约 280 MB，内存与首次打开耗时明显高于普通文档。
- 全量测试中既有的环境类失败（依赖本机 Python 包、LibreOfficeKit 运行时与并发时序）与 main 一致，不属于本次回归；隔离复跑均通过。
