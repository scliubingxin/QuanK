# QuankSight 量见 v1.0.3 发布记录

日期：2026-11-27。版本号 v1.0.3。

安装包：`QuanK-1.0.3-mac-arm64.dmg` / `QuanK-1.0.3-mac-arm64.zip`（下载名 `QuanK-latest.dmg` / `QuanK-mac-arm64.dmg`）。

## 升级提示

1. **先退出旧版本**：在 QuankSight 窗口里按 ⌘Q 退出（不要只关窗口），再把新的 `QuankSight.app` 拖进「应用程序」覆盖旧版本。
2. **第一次打开时，macOS 会弹出钥匙串询问**「QuankSight 想要使用储存在钥匙串中「QuanK Safe Storage」中的机密信息」，请点「始终允许」。点「允许」只对本次有效，下次开机会再问；点「拒绝」则旧密钥读不出来，量化引擎、远程引擎令牌和 Coding 代理密钥需要重新填写。
3. 应用未签名 / 未公证。若被 Gatekeeper 拦住，在「系统设置 → 隐私与安全性」里点「仍要打开」，确认后再次打开即可（新版 macOS 不再支持右键「打开」直接放行）。

## 变更

### 1. 品牌与标语

- 新标语：**量化工作，见机即获**。
- 侧栏品牌改成两行：英文 `QuankSight` 在上，中文「量见 · 量化工作，见机即获」在下，侧栏宽度加到 248px，不再省略成两行三行。
- 版本号不再占据侧栏位置：把鼠标放在侧栏品牌上会显示 `QuankSight v1.0.3`，设置页底部也会以浅灰小字显示「版本 v1.0.3」。

### 2. 安装窗口（DMG）

- 安装窗口换成新品牌背景图（1x / 2x 双分辨率，Retina 不虚），左侧是 QuankSight 图标、右侧是「应用程序」文件夹。
- 说明按新版 macOS 的流程写成「拖进去 → 从启动台打开 → 如果提示未验证开发者，到隐私与安全性点仍要打开」。

### 3. 默认助手名

- 输入框下方的智能体选择器，新用户的默认助手名从「QuanK 助手」改为「**QuankSight 助手**」，自我介绍也改成 QuankSight 工作助手。
- 老用户如果从未改过这个名字（存档里仍是默认的「QuanK 助手」），载入时自动迁移为「QuankSight 助手」；自己改过名字的保持原样，不会被覆盖。

### 4. 其他用户可见的旧名清理

- PDF 预览窗口标题与状态栏：`QuankSight Office · 本机分页预览`、可在 `QuankSight Office` 中继续编辑。
- 仪表盘窗口标题：`QuankSight 仪表盘`。
- 触控 ID 解锁提示：`解锁 QuankSight`。
- 数据目录名、钥匙串身份、`qk.*` 存储键、`QUANK_` 环境变量前缀、`quank` 命令行、仓库链接都保持原样（改这些会让老用户丢数据或读不出密钥）。

## 校验

- `node --check`：对所有 .js / .mjs / .cjs 逐文件检查。
- 单元测试：逐文件运行，失败文件数与 v1.0.2 基线一致（39 个已知失败），无新增。
- 冒烟：`desktop/scripts/smoke-ipc.mjs` 在隔离数据目录下通过。
- 打包：`scripts/package-offline-mac.py` 生成，运行时文件与清单零差异，DMG 窗口背景与图标布局实测（见下表）。
- 打包产物字节数与 sha256 见 GitHub Release 与下载页校验表。

## 已知限制

- 既有的环境类失败（本机 Python 包、LibreOfficeKit 运行时、并发端口占用）与基线一致。
- 应用未签名 / 未公证。
