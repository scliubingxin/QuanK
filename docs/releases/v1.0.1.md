# QuankSight 量见 v1.0.1 发布记录

日期：2026-11-25。版本号 v1.0.1（v1.0.0 的 tag 已推送，按规则不重打 tag、不强推，改发新版本）。

## 变更

### 1. 独立编辑窗口打不开（V100-3）
- `MessageChannelMain` 改为依赖注入：`createOfficeEditWindows()` 要求显式传入 `MessageChannelMain`，缺少时直接抛错；测试里的全局 mock 同步改为参数注入，并新增「不注入即抛错」断言。真实 Electron 不再出现 `MessageChannelMain is not defined`。

### 2. 展开按钮把主区域变空白（V100-3）
- 展开改为覆盖层：不再收缩 `#app`、不再隐藏 `.main`，面板以固定定位覆盖主区域，左边界跟随侧栏右边缘（`--pp-left`），侧栏始终可见；窗口 resize 时重新计算。
- `↙` 语义修正为「在主区域打开」，不再进入展开态；`⤡` 为展开/还原切换，Esc 可还原展开态。

### 3. Office 自动保存一直显示「未保存」
- 输入层自愈：`setPointerCapture` 在标记 drag 之前调用，异常不再中断复位路径；drag/ime 统一走 `setDrag`/`setIme`，document 捕获级 pointerup/pointercancel、`lostpointercapture`、窗口失焦与页面隐藏均复位；`compositionend` 同步复位 ime，不再等 `ime.end` 的 Promise；10/15 秒看门狗兜底。
- 控制器兜底：交互标志超过 20 秒未复位视为过期，照常保存，并在 `QUANK_SELFTEST` 日志记录 `interaction-stale`。
- 隔离真实验证：未修复版本在注入无效 pointerId 的 pointerdown + document pointerup 后 30 秒仍为「未保存」；修复后同一流程 ≤5 秒显示「已保存」，页签预览同步刷新。

### 4. 更名 QuankSight 量见
- 用户可见名称改为「QuankSight 量见」（短名 QuankSight；关于页「量见智能投研软件（QuankSight）」）。
- 数据目录（`Actwill AI`）、`CFBundleIdentifier`、`QUANK_*` 环境变量、keychain service、localStorage 的 `qk.*`、CLI `quank`、MCP 服务名、仓库名与内部文件名保持不变；升级时旧 `QuanK.app` 需拖到废纸篓，数据自动保留。
- 安装包与下载文件名改为 `QuankSight-v1.0.1-mac-arm64.dmg` / `QuankSight-mac-arm64.dmg`（旧下载名保留软链兼容）。
