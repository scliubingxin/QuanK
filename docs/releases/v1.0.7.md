# QuankSight 量见 v1.0.7

Office 编辑窗口的一次集中优化：更接近常用办公软件的分页工具栏、可以直接问文档的 AI 对话面板，以及一批编辑体验修复。

## 新功能

- **分页工具栏**：工具栏按「开始 / 插入 / 设计 / 视图」分页（表格为「开始 / 插入 / 数据 / 视图」），记住上次打开的页签；窗口变窄时次要分组收进「更多 ▾」。
  - 开始：撤销/重做、格式刷、清除格式、字体、字号、增大/减小字号、加粗/倾斜/下划线/删除线、上标/下标、字体颜色/高亮、对齐、项目符号/编号、缩进、行距。
  - 插入：文字文档可插入表格、文本框、形状、分页符、页码、脚注、页眉/页脚；演示文稿可新建幻灯片、文本框、形状；表格可插入/删除行列。
  - 设计：文字文档一键套用标题/副标题/标题 1–3/正文样式；演示文稿可切换 16:9 / 4:3、调整叠放次序、组合/取消组合。
  - 数据（表格）：升序/降序、筛选、自动求和、重新计算；另有自动换行、合并单元格、数字格式与千位分隔。
  - 视图：放大/缩小、适合页面、适合宽度；文字文档可开关修订。
- **AI 对话面板**：标题栏右侧「AI 对话」打开右侧面板，可一键「总结要点」「生成演讲稿」「检查逻辑结构」，也可直接提问；回答只依据文档内容，可一键复制，不会自动写入文档。「优化选中文字」会在选区旁给出逐词对比，确认后才写入。加密、离线或「不上传文档」时面板不可用并说明原因。

## 修复

- **光标**：改为清晰的深色闪烁光标，点击后立即显示，不再等待引擎重绘。
- **工具栏按钮无效**：大部分格式与插入按钮点击后没有反应，现已全部可用；格式参数有误时只提示，不会让编辑器退出。
- **字体**：字体菜单只列出本机实际可用的字体，中文字体（苹方、冬青黑体、黑体、宋体、楷体、仿宋）排在前面；在演示文稿表格单元格中修改中文字体、西文字体和字号都会正确生效并保存。
- **关闭窗口**：关闭时选择「取消」会保留窗口；确认卡片不再出现异常文字。
- **选区 AI**：选中文字后的 AI 菜单恢复可用。

## 暂不支持

- 插入图片、幻灯片放映、演示文稿表格插入将在后续版本提供。

## 升级

直接下载新版 DMG，将 QuankSight 拖入「应用程序」并替换旧版本即可，数据与设置保留。首次启动如出现钥匙串提示，请点「始终允许」。
