# P3 连接器与知识图谱（任务说明，可中断续做）

仓库 `wb-par/quick`，分支 `feat/quick-p3`（自 feat/quick-p2 / 6a00ef8，已含 v0.42.0）。本机优先：同步下来的内容和图谱都存在本机 `workspace.json`；凭据用 macOS 系统安全存储加密，渲染进程永远拿不到明文和密文。

## 用户选择（2026-11-19）
- 数据源：邮件、日历、网页 / RSS 订阅、飞书 / 钉钉 / 企业微信（全部）
- 知识图谱：用当前配置的模型提取实体与关系

## 规则
- 代码由主助手编写；Kiro 只负责测试、提交、推送、打包。
- 每个模块一个提交（前缀 `[p3-mN]`），测试门槛与 P2 相同：新测试单跑 10 次、累计批次 3 次、全量与 `wb-par/_baselines/` 最新名单按名比对无新增（已知 flake 单跑 3 次确认）。
- 用户已授权：模块通过门槛后可自动 graft 推送 GitHub main；**发布 Release 必须先问**。
- 读取类同步由用户在「连接」页亲自添加即视为授权；**发送邮件、发消息、写日历等写操作一律逐次确认**，不进「总是允许」规则。

## 模块
| # | 模块 | 要点 |
|---|---|---|
| M1 | 连接器框架 + 网页 / RSS | 「连接」页：添加、编辑、立即同步、断开、查看内容；同步频率（手动 / 15 分钟 … 每天）；凭据加密；RSS 2.0 / Atom / RDF 解析，普通网页按正文变化跟踪；GBK 等编码；3MB / 20 秒上限；每个连接最多 300 条、总计 3000 条 |
| M2 | 日历 | 订阅链接（.ics / webcal）与 CalDAV（账号 + 应用专用密码）；展开重复日程（未来 30 天）；今天 / 明天的日程 |
| M3 | 邮件 | IMAP over TLS 只读（收件箱最近 N 天、标题 / 发件人 / 摘要），企业邮箱、QQ、163、Outlook 预设；SMTP 发信作为工具，每次确认 |
| M4 | 飞书 / 钉钉 / 企业微信 | 企业自建应用 App ID / Secret；读取：飞书日程与群消息摘要等可读接口；发送：群机器人 Webhook，每次确认 |
| M5 | 知识图谱 | 用当前模型从对话、文档、连接内容中提取实体（人 / 公司 / 项目 / 产品 / 事件）与关系；图谱页浏览、搜索、合并、编辑、删除；对话自动带入相关实体，回复下标明来源；无痕对话不读不写 |
| M6 | 接入 P2 | 对话工具 `connector_search`；每日简报增加「新邮件 / 今日日程 / 订阅更新」；动态显示连接更新；定时任务可引用连接 |

## 进度
- 2026-11-19 P3 启动；M1 编码中。
- M1 已通过门槛（单跑 10/10、批次 3/3、全量无新增），本地提交。
- M2 日历：.ics / webcal 订阅与 CalDAV（well-known → principal → calendar-home-set → REPORT）；RRULE（DAILY/WEEKLY/MONTHLY/YEARLY，BYDAY 含序号、BYMONTHDAY、BYMONTH、COUNT、UNTIL、INTERVAL）、EXDATE、RDATE、RECURRENCE-ID、取消；TZID 含 Windows 名称；快照替换语义。
- M3 邮件：IMAP 只读（LOGIN → ID → EXAMINE → UID SEARCH → UID FETCH BODY.PEEK，不改已读状态），首次同步近 7 天、之后按 UID 增量、UIDVALIDITY 变化自动重置；RFC 2047 / QP / base64 / GBK 解码与正文摘要；SMTP 465 隐式 TLS 或强制 STARTTLS；发信每次系统确认，防头部注入；QQ/163/126/腾讯企业邮/阿里企业邮/飞书/Gmail/Outlook 预设。
- M4 飞书 / 钉钉 / 企业微信：飞书企业自建应用读取机器人所在群近 3 天消息（增量）；钉钉、企业微信只校验应用凭证（开放接口不提供群聊记录）；三平台群机器人 Webhook 发消息（仅官方域名，飞书/钉钉加签），每次系统确认。
- M5 知识图谱：后台用当前模型整理已完成的对话（无痕除外）、文档和连接内容中的人物/公司/项目/产品/事件/地点及关系（先隐藏密钥、手机号等）；按版本增量、每日自动上限 100 次、失败退避 10 分钟；图谱页浏览、搜索、按类型筛选、详情关系图、编辑（之后不被覆盖）、合并、删除（之后不再添加）、删除关系、清空；对话中提到实体名称或别名时自动带入，回复下方标明参考了哪些实体。
- M6 接入 P2：对话 / 定时任务可用只读工具 connector_search（本机已同步内容，无痕对话不可用，结果标注为不可信资料）；每日简报新增「今日日程」「新邮件」「订阅与群消息」（仅在有对应连接时出现）；动态新增「连接」筛选，每次同步带来新内容一条。
