# Demo data spec for manual screenshots (v1.0.6) — fill BEFORE any capture

All data goes into the isolated userData `/private/tmp/shots106-ud` only (assert first). Never the real
`~/Library/Application Support/Actwill AI`. Data is clearly demo (演示) but must look like real use: no empty
lists, no 「暂无数据」, no 「还没有…」 placeholders in any shot.

How to seed: extend the existing seed json used by `/private/tmp/shots106.mjs` (workspace.json shape already
known from h11d-seed.json / h9-seed-chat.json). Where a page fetches live data (quotes, K-line, finance,
announcements), let the app fetch it for real and WAIT until rendered; never write fake prices.

## Gate before every capture
Run in the page: `document.body.innerText` must NOT contain any of
`暂无数据|还没有|没有数据|加载中|空成果|（空文档）|未计算|— 综合分`. If it does: wait up to 60 s, re-check; still
failing → do NOT capture, record `SKIP <fig>: <which placeholder>` in PROGRESS.md.
